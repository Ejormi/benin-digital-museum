Benin Digital Museum 

A responsive and educational website that highlights the rich cultural heritage of the Benin Kingdom. Built using TML and CSS, this project showcases artifacts, historical content, and traditional design elements in a clean and mobile-friendly layout.

---

 Live Website

https://benin-digital-museum.netlify.app

---

 Features

- Informative sections about Benin culture and history  
- Image gallery showcasing artifacts and traditional art  
- Clean and responsive layout for all screen sizes  
- Simple and fast static site  
- Functional contact form using [Basin] for form handling

---

  Technologies Used

- HTML5  
- CSS3  
- [Basin]– used for the backend of the contact form
